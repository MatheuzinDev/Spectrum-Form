# Spectrum Form

Cadastro de clientes: formulário público com validação de CPF, cor preferida servida pelo
banco e área administrativa autenticada.

> **Em construção.** Este README é um marcador. A versão final — instruções de execução,
> comandos e badges — chega na branch `docs/readme-final`, e as decisões de arquitetura
> ficam no `ARQUITETURA.md` a partir de `docs/arquitetura-base`.

## Stack

TypeScript · React + Vite · NestJS sobre Fastify · PostgreSQL + Prisma · Redis · NGINX ·
Docker Compose · pnpm workspaces + Turborepo.

## Requisitos

- Node.js 22+
- pnpm 10+
- Docker (para subir a stack completa)
